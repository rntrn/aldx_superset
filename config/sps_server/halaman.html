Setiap node menjalankan sekumpulan proses. Jumlah proses bernilai auto dihitung sendiri oleh tiap node dari CPU & RAM-nya saat container dinyalakan (auto-tuning), termasuk node yang baru bergabung. Ubah angkanya di tab Pengaturan, lalu terapkan.

Rekomendasi auto-tuning

Menambah node (scale-out)

1. Salin folder D:\superset (termasuk .env) ke komputer baru yang sudah ada Docker Desktop.
2. Di komputer baru: scripts\gabung-node.ps1 -Utama <IP komputer ini>
3. Node muncul di tab Status dalam ±1 menit, lalu di komputer ini jalankan scripts\terapkan-server.ps1 agar gateway ikut membagi beban ke node baru.
Panduan lengkap: docs\11-pusat-kendali-server.md.
Batas ukuran & jumlah baris data yang boleh masuk ke server. auto = dihitung dari RAM & disk server (rumus di tiap baris), angka = batas tetap, 0 = tanpa batas. Berlaku langsung (≤ 10 detik).

Ubah batas

Ekstrak = salinan dataset dari database sumber ke ALDx Engine, database analitik internal. Dashboard menjadi jauh lebih cepat dan sumber tidak terbebani. Aturan hak akses data (RLS) ikut disalin otomatis. Penuh = ganti semua isi (tukar atomik, dashboard tak pernah melihat data setengah jadi); Inkremental = hanya tambah baris yang kolom inkrementalnya lebih besar dari nilai terakhir.
